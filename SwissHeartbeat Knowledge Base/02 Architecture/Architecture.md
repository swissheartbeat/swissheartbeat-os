# Architecture

## Überblick

SwissHeartbeat ist als modernes, modulares Knowledge Operating System aufgebaut.

Die Plattform besteht aus einem Frontend, einem Backend, einer Datenbank und einer Knowledge Engine.

---

## Systemarchitektur

Frontend
- Next.js
- React
- TypeScript

Backend
- NestJS
- REST API

Datenbank
- PostgreSQL
- Prisma ORM

Infrastructure
- Docker
- GitHub
- Git

---

## Grundprinzipien

- Modularer Aufbau
- API First
- Cloud Ready
- Skalierbar
- Open Standards
- Security by Design

---

## Hauptmodule

- Signal
- Evidence
- Knowledge
- Trust Engine
- Publishing
